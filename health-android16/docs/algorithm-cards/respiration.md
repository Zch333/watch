# Respiration 1.0.0

- Intended use: vendor/platform respiratory-rate trend.
- Inputs: qualified `RESPIRATORY_RATE` values with unit/catalog semantics confirmed.
- Method/output: median count per reported platform interval.
- Quality gate: no value is shown when capability/semantics/quality are unknown.
- Evidence: E0 vendor-unverified pending GT6/Health Service confirmation.
- Failure modes: sleep/wake context, algorithm updates, sparse records and unit ambiguity.
- License: proprietary application aggregation.
- Prohibited claims: respiratory disease, infection or sleep-apnoea diagnosis.
