# Sleep 1.0.0

- Intended use: sleep duration, descriptive debt against an 8-hour reference and start-time regularity.
- Inputs: qualified platform duration/start records; vendor stages are display context only.
- Method/output: summed minutes, non-negative reference difference, circular start-time regularity score.
- Quality gate: empty/stale/rejected nights do not produce a precise summary.
- Evidence: E1 engineering; stage accuracy and GT6 semantics require paired device validation.
- Failure modes: naps/fragmentation, timezone travel, missing wear, platform episode correction.
- License: proprietary application code.
- Prohibited claims: PSG equivalence, insomnia or sleep-apnoea diagnosis.
