# Temperature 1.0.0

- Intended use: separate skin/body temperature trends.
- Inputs: qualified Celsius observations; source type and sensor location must remain explicit.
- Method/output: per-type median Celsius; types are never merged.
- Quality gate: 20–45°C semantic guard plus capability/quality requirements.
- Evidence: E0 vendor-unverified until device type and measurement meaning are confirmed.
- Failure modes: ambient temperature, contact, exercise, circadian timing and mislabeled skin/body values.
- License: proprietary application code; descriptive statistic unrestricted.
- Prohibited claims: fever, infection, ovulation, pregnancy or disease detection.
