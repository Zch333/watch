# ADR-0001：Standalone-first

> 文档体系：FUNAR × Functional DDD × Hexagonal Architecture  
> 项目：Move25 for HUAWEI WATCH GT 6  
> 版本：v2.0  
> 编制日期：2026-08-05  
> 状态：架构基线；后台提醒能力仍需 GT6 真机探针确认

## 状态

接受，但受能力门禁约束。

## 决策

正式产品不开发必需的手机伴随应用；设置、计划和状态保存在手表端。手机只承担运动健康配对、应用市场安装和开发调试链路。

## 理由

用户当前使用 vivo，未来可能更换 iPhone 或 HarmonyOS 手机。GT6 官方兼容性清单显示这些生态均支持运动健康应用市场。[H2]

## 后果

- 获得日常跨手机生态独立性；
- 后台提醒必须由手表本地能力完成；
- 若能力门禁失败，本 ADR 需要重新打开，不能用不可靠前台计时掩盖。
