# 健康分析后端

后端同时接收 Android Health Service Kit 数据与 Huawei Cloud REST 数据，按平台记录 ID 或稳定语义键幂等合并。原始数据先归一、质量评估、特征计算、基线和变化检测，再构造最小 `AiEnvelope`。

DeepSeek 只在服务端适配器中读取密钥，只输出 JSON 解释。所有数值、异常、置信度和红旗以确定性引擎为准；AI Schema、事实引用或医学边界校验失败时，自动退回模板报告。

正式部署仍需实现网络、数据库、密钥库、鉴权、限流、加密、删除传播、审计和 Huawei OAuth/Scope；当前仓库只提供平台无关内核、端口和契约测试，未伪造任何外部凭据或服务批准。
